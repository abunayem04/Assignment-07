# বাজার দর (Bazar Dor)

বাজার দর হলো একটি ওয়েব অ্যাপ্লিকেশন যার মাধ্যমে বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের প্রতিদিনের বাজারদর, দামের ওঠানামা এবং বিভিন্ন বাজারের তুলনামূলক দাম দেখা যায়।

## গুরুত্বপূর্ণ লিংকসমূহ

- **লাইভ ওয়েবসাইট:** [https://assignment-07-nine-rho.vercel.app/](https://assignment-07-nine-rho.vercel.app/)
- **গিটহাব রিপোজিটরি:** [https://github.com/abunayem04/Assignment-07](https://github.com/abunayem04/Assignment-07)

## ব্যবহৃত প্রযুক্তিসমূহ (Technologies Used)

- **Frontend:** Next.js (App Router), React, TypeScript
- **Styling:** Tailwind CSS
- **Authentication:** Better Auth (MongoDB Adapter)
- **Database:** MongoDB Atlas
- **Icons & UI:** Lucide React, React Hot Toast

## মূল ফিচারসমূহ (Key Features)

1. **লাইভ প্রাইস টিকার (Price Ticker):** হোমপেজে স্বয়ংক্রিয়ভাবে স্ক্রলিং করা টিকার যেখানে আজকের পণ্যের নাম ও দামের পরিবর্তন শতকরা হারে দেখা যায়।
2. **হোমপেজ সেকশন বিন্যাস:** হিরো সেকশনের পরে ক্রমানুসারে "আজ দাম বেড়েছে", "আজ দাম কমেছে" এবং "সব পণ্য" সেকশন।
3. **বাংলা সংখ্যা অনুযায়ী শর্টিং (Price Sorting):** পণ্যসমূহের দাম বাংলা সংখ্যা হওয়া সত্ত্বেও কম থেকে বেশি বা বেশি থেকে কম অনুযায়ী সঠিকভাবে শর্ট করা যায়।
4. **সুরক্ষিত প্রোডাক্ট বিস্তারিত পেজ (Protected Details):** পণ্যের বিস্তারিত পেজটি শুধুমাত্র লগইন করা ইউজাররা দেখতে পারেন এবং সেখানে বিভিন্ন বাজারের দামের তুলনা টেবিল রয়েছে।
5. **অথেন্টিকেশন ও প্রোফাইল আপডেট (Profile Management):** ইমেইল-পাসওয়ার্ড এবং গুগল/গিটহাব দিয়ে লগইন এবং প্রোফাইল থেকে ইউজারের নাম আপডেট করার সুবিধা।
6. **মাল্টিপল API ব্যাকআপ সাপোর্ট:** মূল API (Programming Hero OpenAPI) ডাউন থাকলেও স্বয়ংক্রিয়ভাবে ব্যাকআপ API থেকে ডেটা লোড হয়।
7. **সম্পূর্ণ রেসপনসিভ ডিজাইন:** মোবাইল, ট্যাবলেট এবং ডেস্কটপ সব ডিভাইসেই সহজে ব্যবহারযোগ্য।

## লোকাল সেটআপ (How to Run Locally)

১. রিপোজিটরি ক্লোন করুন:
```bash
git clone https://github.com/abunayem04/Assignment-07.git
cd Assignment-07
```

২. ডিপেনডেন্সি ইন্সটল করুন:
```bash
npm install
```

৩. ডেভেলপমেন্ট সার্ভার রান করুন:
```bash
npm run dev
```

ব্রাউজারে `http://localhost:3000` ওপেন করে প্রজেক্টটি দেখুন।
